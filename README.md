## 三、实验原理
### 1. LinearLayout 线性布局
线性布局是Android中最基础的布局容器，其子控件会沿着单一方向依次排列，排列方向可设置为水平横向或垂直纵向。通过权重属性可以按比例分配布局内的剩余空间，适合结构简单的行列类界面；缺点是多层嵌套会增加视图渲染的开销，不适合复杂界面。

### 2. TableLayout 表格布局
表格布局以行和列的形式组织子控件，每一行由一个TableRow控件代表，TableRow内部的控件自动成为表格的单元格。布局会自动对齐所有行的列，无需额外设置即可实现列宽统一，适合菜单、数据表格等规整的界面场景。

### 3. ConstraintLayout 约束布局
约束布局是Android官方推荐的主流布局，通过控件与控件之间、控件与父容器之间的相对位置约束来确定控件的位置，无需嵌套多层布局即可实现复杂界面。它能够有效降低布局的层级深度，提升界面渲染性能，适配不同屏幕尺寸的灵活性更强。

### 4. Jetpack Compose
Jetpack Compose是Android新一代声明式UI框架，通过代码直接描述界面样式，依靠状态驱动界面刷新。其中Column和Row组件对应传统的线性布局，LazyColumn组件可实现高性能的可滚动列表；通过状态记忆机制跟踪数据变化，数据更新时界面会自动同步刷新，无需手动操控控件。

## 四、实验内容与实现过程
### 4.1 线性布局实现4×4文本界面
本实验要求使用线性布局实现4行4列的文本排列界面，每行依次显示对应行列编号的文本内容。

实现过程中，以垂直方向的线性布局作为根容器，在根布局内部依次添加4个水平方向的线性布局，每一个水平线性布局代表一行。每行内部放置4个文本控件，并为每个文本控件设置相等的权重值，使4个文本控件自动平均分配每行的水平宽度，最终形成规整的4行4列网格文本效果。

### 4.2 表格布局实现菜单界面
本实验要求使用表格布局实现类似软件菜单栏的界面，包含菜单项名称与对应的快捷键，菜单项包括打开、保存、另存为、导入、导出、退出等选项。

实现过程中，直接以表格布局作为根容器，每一行菜单对应一个TableRow控件。每个TableRow内部放置两个文本控件，左侧文本显示菜单项名称，右侧文本显示对应的快捷键。表格布局会自动统一所有行的列宽，使第一列菜单文字左对齐、第二列快捷键右对齐，整体呈现出标准的菜单排列效果。

### 4.3 约束布局实现计算器界面
本实验要求使用约束布局实现简易计算器界面，包含标题、输入显示区域以及数字按键区域。

实现过程中，以约束布局作为根布局，顶部依次放置界面标题、输入框与结果显示区域。下方的数字按键通过两两之间的横向、纵向约束进行定位，每个按键与相邻的按键建立左右对齐与上下对齐关系，无需嵌套任何其他布局容器，仅通过一层约束布局就完成了所有按键的网格状排列，界面层级十分扁平。

### 4.4 约束布局实现机票预订界面
本实验要求使用约束布局实现机票预订界面，包含标题栏、行程类型、出发地、目的地、出行人数、出发日期等信息模块与图片元素。

实现过程中，以约束布局作为根容器，顶部放置界面标题与行程类型选择区域；中部依次排列出发地、目的地、出行人数、出发日期等信息模块，每个模块通过与父容器的左右边距约束、与上方模块的纵向间距约束固定位置；界面中的图片控件通过约束对齐到对应信息区域。所有元素通过相对约束有序排布，适配不同屏幕尺寸时布局稳定性更强。

### 4.5 Jetpack Compose实现任务列表
本实验要求使用Jetpack Compose实现可交互的课程学习任务列表，支持添加任务、勾选任务、删除任务，且勾选任务后已完成数量和任务文本删除线会同步更新。

实现过程中，使用Column组件搭建整体垂直结构，顶部为标题区域、任务输入框与添加按钮；中间列表区域使用LazyColumn组件渲染所有任务项，每一项任务包含复选框、任务文本与删除按钮。

通过状态管理机制维护任务列表数据与每个任务的完成状态：点击添加按钮时，将输入框内的内容加入任务列表，任务总数同步增加；勾选任务复选框时，对应任务标记为已完成，已完成任务计数自动更新，同时任务文本自动添加删除线效果；点击删除按钮时，对应任务从列表中移除，总数与完成数同步刷新。整个界面完全由数据状态驱动，数据变化时界面自动更新。

## 五、实验结果
本次实验的五项布局任务均成功实现预期效果：
1. 线性布局界面准确呈现4行4列的文本网格，行列对齐整齐，权重分配符合预期。
2. 表格布局菜单界面列对齐准确，菜单项与快捷键对应清晰，呈现出规整的菜单样式。
3. 约束布局计算器界面按键排列整齐，布局层级仅为一层，验证了约束布局扁平化的优势。
4. 约束布局机票界面信息模块排布有序，各元素位置准确，适配性良好。
5. Compose任务列表实现了添加、勾选、删除的完整交互，状态更新同步准确，列表滚动流畅。

## 六、实验总结
本次实验通过实现五个不同的界面，全面掌握了Android四种布局方案的特点与用法。传统XML布局中，线性布局适合简单行列结构，表格布局适合规整表格类界面，而约束布局在复杂界面中优势显著，既能减少布局嵌套提升性能，又能提高屏幕适配性。Jetpack Compose作为新一代UI框架，声明式的开发方式更简洁，状态驱动的逻辑让交互实现更直观，开发效率相比传统XML布局有明显提升。

通过本次实验，理解了不同布局的选型原则，在实际开发中需要根据界面的复杂程度选择最合适的布局方案，合理搭配使用才能兼顾开发效率与运行性能。
